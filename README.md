# 🛡️ Auditoría de Ciberseguridad: Entornos PLC y Modbus

## 📝 Descripción
Este proyecto es un análisis detallado de vulnerabilidades en sistemas de control industrial (ICS). El objetivo fue identificar vectores de ataque en el protocolo Modbus y proponer medidas de mitigación efectivas.

## 🛠️ Herramientas Utilizadas
* **Análisis de Tráfico:** Wireshark
* **Simulación:** (Ej: Factory IO, OpenPLC o el que usaras)
* **Escaneo:** Nmap (scripts específicos de SCADA)
* **Frameworks:** NIST SP 800-82 / IEC 62443

## 🚀 Puntos Clave del Análisis
1. Identificación de activos en la red OT.
2. Intercepción y manipulación de registros Modbus.
3. Propuesta de segmentación de red (VLANs) y Firewalls industriales.
